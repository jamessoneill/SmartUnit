# Security policy

**Status:** research preview / unreleased. Do not use SmartUnit as a substitute for full verification in security-sensitive CI pipelines.

If you find a vulnerability that could cause an incorrect skip, malicious cache interpretation, code execution or leakage of secrets, please **do not post exploit details in a public issue**. Use the GitHub repository's **Security → Report a vulnerability** private advisory feature once it is enabled, or reach maintainers through a private channel published by the repository owner.

There is currently no production version support promise or guaranteed response time. Public releases should include a changelog with security-relevant fixes and migration guidance for cache format changes.
